优先级队列是一种基于[二叉堆](/Algorithm/%E6%95%B0%E6%8D%AE%E7%BB%93%E6%9E%84/%E5%A0%86/%E4%BA%8C%E5%8F%89%E5%A0%86/)的数据结构。

优先级队列会使用到[二叉堆](/Algorithm/%E6%95%B0%E6%8D%AE%E7%BB%93%E6%9E%84/%E5%A0%86/%E4%BA%8C%E5%8F%89%E5%A0%86/)的[二叉堆](/Algorithm/%E6%95%B0%E6%8D%AE%E7%BB%93%E6%9E%84/%E5%A0%86/%E4%BA%8C%E5%8F%89%E5%A0%86/#%E5%A0%86%E5%8C%96%E4%B8%8B%E6%B2%89)和[二叉堆](/Algorithm/%E6%95%B0%E6%8D%AE%E7%BB%93%E6%9E%84/%E5%A0%86/%E4%BA%8C%E5%8F%89%E5%A0%86/#%E5%A0%86%E5%8C%96%E4%B8%8A%E6%B5%AE) 操作。

## 入队

```cpp
template<class T>
void Enqueue(T item, int priority)
{
    heap.Add(new PriorityItem(item, priority));
    ShiftUp(heap, heap.length, heap.length - 1);
}
```

## 出队

```cpp
template<class T>
T Dequeue()
{
    if (heap.Count == 0)
        throw new InvalidOperationException("Queue is empty");

    T result = heap[0].Item;
    // 将最后一个元素移到堆顶
    heap[0] = heap[heap.Count - 1];
    heap.RemoveAt(heap.Count - 1);
    if (heap.Count > 0)
        HeapifyDown(heap, heap.length, 0);
    return result;
}
```
