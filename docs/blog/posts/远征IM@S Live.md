国内 P 如何远征偶像大师 Live
<!-- more -->

## 确定企划 Live 时间, 地点, 出演人员

偶像大师公式门户站 https://idolmaster-official.jp/  
找到其中的ライブ/イベント, 可以看到相关的所有信息。

## 注册账号

Asobi Store https://asobistore.jp/  
注册时居住国家需选择日本, 出生日期必须匹配, 出票会进行比对。

注册成功后 Event 界面可以进行购票。

## 信息录入

填写个人信息时, 不要输入汉字, 输入拼音。

地址在地图上随便找一个公寓地址, 不要填写一户建或商家, 避免被投诉。

电话随便填写一个。

## 票种

出售票种：
1. **抽选** 全席位指定(最普通的坐票)和更好的位置。
2. **先着** 剩余的全席指定和好票, 立见指定票和位置较差的票。
3. **公式リセール** 官方换票。
4. **当日票** 售票时间较晚的票, 全席指定没卖完。

一般抽选的票体验最好, 但官方公布较晚, 甚至当天才会公布, 需要多关注推特或者公演官网。

## 席位

席位种类：
1. **全席指定** 坐票, 好坏皆有
2. **立见指定** 站票, 告别好席, 主舞台可能被遮挡
3. **着席指定** 全程就坐, 不能爽打 Call
4. **見切り席/完全見切り席** 被遮挡席位, 无法完整看到甚至无法看到表演
5. **SS 席/S 席** 好位置票, 通常带特典
6. **SPラウンジ席** VIP 休息间席位
7. **バルコニー席** 露台席, 离舞台较远

## 大会员

大会员抽票一般先行且更可能抽到好票。

在 ASOBI STORE 的プレミアム会とは 可以进入大会员商店。

注意大会员要开就开年票, 月票是无法参与大会员抽选的。

开大会员需要办理一张 JCB 的卡, Visa 卡基本不可以开通。
